# Performance AI

Aplicación personal para planificar entrenamientos, registrar cargas y revisar progreso.

## Publicación

1. Subir `index.html` de Performance AI V5 a la raíz de este repositorio mediante **Add file → Upload files**.
2. En **Settings → Pages**, seleccionar **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardar.
3. Abrir `https://agusraviolo1-collab.github.io/performance-ai/` y verificar la navegación en Safari.

Los datos guardados con `localStorage` permanecen en cada navegador y no se sincronizan entre dispositivos. Evitar introducir datos personales sensibles en un repositorio público.
